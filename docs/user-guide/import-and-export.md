# Import and export

You'll find all of this in **Settings**, under **Your data**. Importing needs a connection to your server.

## Export your data

**Export JSON** downloads everything in your account: routines, workouts, exercises, and bodyweight entries. Use it as a personal backup, or to move to another Granite server.

## Import a Granite export

**Import JSON** loads a file you exported earlier. Records are matched by id, so importing the same file twice won't create duplicates.

## Import from Hevy

If you're coming from Hevy, export your workout history there as a CSV file, then choose **Import from Hevy (CSV)**.

Granite matches exercise names to its built-in library, and creates custom exercises for anything it doesn't recognize. Importing the same file again updates those workouts rather than duplicating them.

## Server backups

Exports cover your own account. If you run the server, see [Backups and restore](../self-hosting/backups.md) to protect the whole instance.
